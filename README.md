# gaknui-checker

学マスのぬいぐるみかどうかを判定できるアプリケーション

## 構成

```
.
├── data/
│   ├── raw/            # スクレイピングしたままの生データ
│   └── processed/      # リサイズ・正規化済みの学習用データ
├── scripts/            # 実行用スクリプト
├── notebooks/          # 学習の試行錯誤（Jupyter Notebook / Colab）
│   └── training.ipynb  
├── models/             # 学習済みモデルの保存先（.h5, .tflite, .json等）
└── web/                # フロントエンド（React / Next.js等）
    ├── public/models/  # ブラウザからロードするモデル配置先
    └── src/            # Webアプリのソースコード
```

## 構想

1. 学習用データをスクレイピングして集める

学マスのぬいぐるみの画像データはインターネットに無限にあるので学習データとして拾ってくる

2. モデル学習

ぬいの種類を判定できる機械学習モデルをつくる

3. web フロントエンド

フロントエンド上に乗るくらいにモデルを軽量化してデバイス上でモデルが動くようにする。カメラと連動できると◎

## 学習について

画像の下処理（破損データの除去とリサイズ）は学習前に終わらせておく（学習に組み込む意味はないし画像のサイズも圧縮できるので）。
画像の拡張は学習時に行うことでストレージの節約をする。

### 画像の下処理

[Pillow](https://pypi.org/project/pillow/)が定番なので採用。
